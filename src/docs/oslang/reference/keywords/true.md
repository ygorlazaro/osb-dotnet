# TRUE

Boolean true literal.

## Syntax

```osl
TRUE
```

## Description

`TRUE` is a literal boolean value representing logical truth.

## Example

```osl
VAR isReady = TRUE
IF isReady = TRUE THEN
    PRINT "Ready"
END IF
```
