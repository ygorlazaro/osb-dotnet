# Keywords Reference

This section documents every keyword in OSLANG. Keywords are reserved words that have special meaning and cannot be used as identifiers.

## A

- **[AND](/src/docs/oslang/reference/keywords/and.md)** — Logical conjunction.

## B

- **[BASE](/src/docs/oslang/reference/keywords/base.md)** — Calls the base class implementation.
- **[BOOL](/src/docs/oslang/reference/keywords/bool.md)** — Converts a value to a boolean.
- **[BOOLEAN](/src/docs/oslang/reference/keywords/boolean.md)** — Boolean type annotation.
- **[BREAK](/src/docs/oslang/reference/keywords/break.md)** — Exits a loop.

## C

- **[CATCH](/src/docs/oslang/reference/keywords/catch.md)** — Catches a runtime error.
- **[CLASS](/src/docs/oslang/reference/keywords/class.md)** — Defines a class.
- **[CONSTRUCTOR](/src/docs/oslang/reference/keywords/constructor.md)** — Defines a class constructor.
- **[CONTINUE](/src/docs/oslang/reference/keywords/continue.md)** — Skips to the next loop iteration.

## D

- **[COUNT](/src/docs/oslang/reference/keywords/count.md)** — Returns the number of items in a collection.
- **[DO](/src/docs/oslang/reference/keywords/do.md)** — Starts a do/while loop.

## E

- **[ELIF](/src/docs/oslang/reference/keywords/elif.md)** — Else-if branch.
- **[ELSE](/src/docs/oslang/reference/keywords/else.md)** — Else branch.
- **[END](/src/docs/oslang/reference/keywords/end.md)** — Ends a block.

## F

- **[FALSE](/src/docs/oslang/reference/keywords/false.md)** — Boolean false literal.
- **[FLOOR](/src/docs/oslang/reference/keywords/floor.md)** — Rounds down to the nearest integer.
- **[FOR](/src/docs/oslang/reference/keywords/for.md)** — For loop.
- **[FUNCTION](/src/docs/oslang/reference/keywords/function.md)** — Defines a function.
- **[FUNCTION](/src/docs/oslang/reference/keywords/function.md)** — Defines a function.

## G

- **[GLOBAL](/src/docs/oslang/reference/keywords/global.md)** — Declares a global variable.

## I

- **[IF](/src/docs/oslang/reference/keywords/if.md)** — Conditional statement.
- **[INPUT](/src/docs/oslang/reference/keywords/input.md)** — Reads input from the user.
- **[INTERFACE](/src/docs/oslang/reference/keywords/interface.md)** — Defines an interface.

## M

- **[ME](/src/docs/oslang/reference/keywords/me.md)** — Refers to the current object instance.
- **[NEW](/src/docs/oslang/reference/keywords/new.md)** — Creates a new object instance.
- **[NOT](/src/docs/oslang/reference/keywords/not.md)** — Logical negation.
- **[NULL](/src/docs/oslang/reference/keywords/null.md)** — Represents no value.
- **[NUMBER](/src/docs/oslang/reference/keywords/number.md)** — Number type annotation.
- **[NUMBER](/src/docs/oslang/reference/keywords/number.md)** — Converts a value to a number.

## O

- **[OBJECT](/src/docs/oslang/reference/keywords/object.md)** — Base type for all objects.
- **[OR](/src/docs/oslang/reference/keywords/or.md)** — Logical disjunction.
- **[OVERRIDE](/src/docs/oslang/reference/keywords/override.md)** — Overrides a virtual method.

## P

- **[PRINT](/src/docs/oslang/reference/keywords/print.md)** — Outputs text to the console.
- **[PRIVATE](/src/docs/oslang/reference/keywords/private.md)** — Private visibility modifier.
- **[PROTECTED](/src/docs/oslang/reference/keywords/protected.md)** — Protected visibility modifier.
- **[PUBLIC](/src/docs/oslang/reference/keywords/public.md)** — Public visibility modifier.

## R

- **[RAISE](/src/docs/oslang/reference/keywords/raise.md)** — Raises an event.
- **[RETURN](/src/docs/oslang/reference/keywords/return.md)** — Returns from a function.

## S

- **[SQRT](/src/docs/oslang/reference/keywords/sqrt.md)** — Square root function.
- **[STEP](/src/docs/oslang/reference/keywords/step.md)** — Step increment in a for loop.
- **[STR](/src/docs/oslang/reference/keywords/str.md)** — Converts a value to a string.
- **[STRING](/src/docs/oslang/reference/keywords/string.md)** — String type annotation.
- **[SWITCH](/src/docs/oslang/reference/keywords/switch.md)** — Switch statement or expression.

## T

- **[THEN](/src/docs/oslang/reference/keywords/then.md)** — Separates condition from body in IF.
- **[TO](/src/docs/oslang/reference/keywords/to.md)** — End of range in FOR loop.
- **[TRUE](/src/docs/oslang/reference/keywords/true.md)** — Boolean true literal.
- **[TRY](/src/docs/oslang/reference/keywords/try.md)** — Starts a try block.
- **[TYPEOF](/src/docs/oslang/reference/keywords/typeof.md)** — Returns the type name of a value.

## U

- **[USING](/src/docs/oslang/reference/keywords/using.md)** — Imports a module.

- **[VIRTUAL](/src/docs/oslang/reference/keywords/virtual.md)** — Declares a virtual method.

- **[WHILE](/src/docs/oslang/reference/keywords/while.md)** — While loop.
