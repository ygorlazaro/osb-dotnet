# SQRT

Returns the square root of a number.

## Syntax

```osl
SQRT(value)
```

## Description

`SQRT()` computes the square root of `value`. The argument must be a non-negative number.

## Example

```osl
PRINT SQRT(16)   ' 4
PRINT SQRT(2)    ' 1.4142135623730951
```
