# TO

Ends the range in a `FOR` loop.

## Syntax

```osl
FOR variable = start TO end [STEP increment]
    ' statements
END
```

## Description

`TO` separates the start and end values of the loop range.

## Example

```osl
FOR i = 1 TO 5
    PRINT i
END
```
