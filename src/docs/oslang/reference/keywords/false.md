# FALSE

Boolean false literal.

## Syntax

```osl
FALSE
```

## Description

`FALSE` is a literal boolean value representing logical falsehood.

## Example

```osl
VAR isDone = FALSE
IF isDone = FALSE THEN
    PRINT "Not done"
END IF
```
