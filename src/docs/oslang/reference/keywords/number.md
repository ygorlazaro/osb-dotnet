# NUMBER

Number type annotation and conversion.

## As a Type Annotation

```osl
VAR count NUMBER
```

Declares a variable intended to hold a numeric value.

## As a Built-in Function

```osl
NUMBER(value)
```

Converts `value` to a `NUMBER`.

## Example

```osl
VAR age NUMBER = 25
VAR score = NUMBER("95.5")
```
