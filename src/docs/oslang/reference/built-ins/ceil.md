# CEIL

Rounds a number up to the nearest integer.

## Syntax

```osl
CEIL(value)
```

## Description

`CEIL()` returns the smallest integer greater than or equal to `value`.

## Example

```osl
PRINT CEIL(3.2)   ' 4
PRINT CEIL(-2.3)  ' -2
PRINT CEIL(5.0)   ' 5
```
