# POW

Raises a number to a power.

## Syntax

```osl
POW(base, exponent)
```

## Description

`POW()` returns `base` raised to the power of `exponent`.

## Example

```osl
PRINT POW(2, 3)   ' 8
PRINT POW(3, 2)   ' 9
PRINT POW(2, -1)  ' 0.5
```
