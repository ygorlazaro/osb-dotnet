# ABS

Returns the absolute value of a number.

## Syntax

```osl
ABS(value)
```

## Description

`ABS()` returns the non-negative magnitude of `value`.

## Example

```osl
PRINT ABS(-5)    ' 5
PRINT ABS(10)    ' 10
PRINT ABS(0)     ' 0
```
