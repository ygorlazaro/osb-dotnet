# FLOOR

Rounds a number down to the nearest integer.

## Syntax

```osl
FLOOR(value)
```

## Description

`FLOOR()` returns the largest integer less than or equal to `value`.

## Example

```osl
PRINT FLOOR(3.7)   ' 3
PRINT FLOOR(-2.3)  ' -3
PRINT FLOOR(5.0)   ' 5
```
